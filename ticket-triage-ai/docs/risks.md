# Реестр рисков

Оценки предварительные, не результаты анализа данных. Владелец каждого риска — автор проекта в указанной роли.

| Риск | Вероятность | Влияние | Ранний сигнал | Профилактика | План Б | Роль |
|---|---|---|---|---|---|---|
| Мало критических заявок | Высокая | Высокое | Мало примеров в каждой выборке | На шаге проверки данных посчитать классы; изучить веса классов | Запросить дополнительные размеченные примеры | ML |
| Ошибочные исторические метки | Средняя | Высокое | Похожие тексты имеют противоречивые метки | До обучения проверить спорные примеры | Исключить спорные записи с описанием причины | Аналитик |
| Пропуск критических заявок | Средняя | Высокое | Recall критических < 0,80 | Отдельная оценка класса, настройка по валидации | Оставить ручную обработку, не объявлять модель принятой | ML |
| API и UI используют разные поля | Средняя | Среднее | Ответ не отображается | До интеграции согласовать формат и искусственный пример | Исправить контракт до демонстрации | Разработчик |
| Не повторяется запуск | Средняя | Высокое | Ошибка на чистом окружении | При реализации фиксировать зависимости и инструкцию | Подготовить проверенное демонстрационное окружение | Разработчик / QA |

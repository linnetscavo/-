# Проверки текущей поставки
Дата проверки 11 ноября 2026 года. Среда Windows, Python 3.13.5, версии библиотек указаны в requirements.txt. Все примеры и CSV синтетические.

Семь автоматических тестов прошли через python -m unittest -v. Покрыты схема, совместимость меток, воспроизводимость генератора, размер и распределение учебного набора, разбиение, отсутствие слов validation/test в словаре TF-IDF, матрицы ошибок, критические пропуски, подтверждение и коррекция оператора, повторная запись решения, дефекты данных без изменения исходной таблицы и маркировка синтетики.

Все кодовые ячейки data_checks.ipynb и experiment.ipynb выполнены без ошибок. На CSV из 12 000 строк получены части train 8 000, validation 2 000, test 2 000. Обе задачи прошли полный путь обучения и оценки. Поле acceptance в run.json равно null, mode равно SYNTHETIC. Числовые ML-результаты локального прогона доступны в runs/SYNTHETIC и выводах выполненного notebook. Публикуемые notebook имеют очищенные выводы и воспроизводят результаты при запуске.

При исполнении Jupyter в Windows было предупреждение zmq о дополнительном потоке обработки событий. Оба notebook завершились успешно.

Настоящие метрики приёмки, историческая разметка, HTTP API, графическая форма, задержка API и установка в новом чистом окружении ожидают соответствующей реализации и проверки. Эти пункты отражены в backlog.

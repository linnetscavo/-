# Проверка синтетического CSV
Проверка выполнена 11 ноября 2026 года на собственном учебном наборе. Режим SYNTHETIC. Исторические обращения не использовались. Источник состоит из шаблонов create_synthetic_csv.py с seed 42.

## Размер и поля
Загружено 12,000 строк и 6 столбцов. Поля id, subject, text, department, priority и data_origin загружаются pandas как object со строковыми значениями. Уникальных ID 12,000. Количество null и пустых значений по каждому из шести столбцов равно 0, доля пропусков равна 0. Дополнительное поле data_origin всегда равно SYNTHETIC и исключается из признаков.

## Проверки дефектов
Количество включает все строки, участвующие в найденной проблеме. Проверки выполняются после нормализации пробелов и допустимых названий приоритета. Строки при этом сохраняются.

| Проверка | Количество строк |
|---|---|
| empty_id | 0 |
| duplicate_id | 0 |
| duplicate_row | 0 |
| duplicate_text | 0 |
| empty_subject | 0 |
| empty_text | 0 |
| empty_input | 0 |
| short_input | 0 |
| unknown_priority | 0 |
| empty_department | 0 |
| unknown_department | 0 |

## Распределение приоритетов
| Приоритет | Количество |
|---|---|
| стандартный | 6000 |
| низкий | 3000 |
| высокий | 2400 |
| критический | 600 |

Пять учебных подразделений содержат по 2 400 строк. Их названия и частоты приоритетов заданы генератором. Коротким считается объединённый текст длиной от 1 до 19 символов. Словари приоритетов и подразделений проверены. Это измерение сгенерированного набора, распределения реальной поддержки пока неизвестны.

## Преобразования
При чтении сохраняется строковый ID и поддерживается UTF-8 с BOM. Проверка формирует нормализованную копию для диагностики. При обучении удаляются крайние пробелы, отсутствующий текстовый фрагмент заменяется пустой строкой, старые значения low/medium/standard/high/critical и средний приводятся к принятым приоритетам. Исходный CSV остаётся доступным для сверки. Строки автоматически не удаляются. Критические заявки сохранены.

Уникальный код учебного сценария создан генератором и обеспечивает отсутствие точных дублей. Текстовые шаблоны напрямую выражают признаки подразделения и срочности. Это искусственное упрощение ограничивает интерпретацию ML-метрик.

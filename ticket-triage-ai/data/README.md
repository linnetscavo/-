# Данные

- `examples/` — только вручную созданные искусственные примеры, разрешённые для git.
- `raw/` — локальные исходные данные; содержимое исключено из git.
- `processed/` — локальные очищенные данные и выборки; содержимое исключено из git.

По условию ожидаются 12 000 заявок, но выгрузка в проект не добавлена. Схема и правила проверки — в `../docs/data-schema.md`. Даже обезличенную реальную выгрузку не публикуем. `.gitignore` не распознаёт персональные данные автоматически.

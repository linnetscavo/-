# Данные
examples/ содержит искусственный пример одной записи из первого практикума. synthetic/ содержит собственный синтетический CSV на 12 000 строк, генератор описан в его README. raw/ и processed/ предназначены для будущих локальных исходных и подготовленных исторических данных и исключены из git.

По условию ожидаются 12 000 исторических заявок. Фактическая выгрузка пока отсутствует. Синтетические данные созданы по решению для учебной проверки. Схема находится в ../docs/data-schema.md. .gitignore разрешает конкретный синтетический CSV и блокирует остальные CSV по умолчанию.

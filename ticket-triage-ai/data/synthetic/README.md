# Синтетические заявки
Файл tickets_synthetic.csv содержит 12 000 искусственно сгенерированных заявок. Источник состоит из шаблонов create_synthetic_csv.py. Seed равен 42. Набор включает пять вымышленных подразделений и четыре приоритета. Каждая строка имеет data_origin=SYNTHETIC и ID с префиксом SYN-. Исторические обращения и клиентские данные при создании не используются.

Частоты заданы явно для проверки дисбаланса. Низкий приоритет составляет 25%, стандартный 50%, высокий 20%, критический 5%. Это параметры генерации. Распределение реальной службы поддержки неизвестно. В тексты добавлен уникальный код учебного сценария для предотвращения точных дублей между выборками. Шаблоны и уникальные коды упрощают задачу и ограничивают применимость полученных метрик.

Для воспроизведения из корня проекта выполнить python create_synthetic_csv.py. CSV записывается в UTF-8 с BOM, разделитель — запятая. Файл .metadata.json содержит число строк, seed, частоты, источник и SHA-256 CSV. Повторный запуск перезаписывает только указанный синтетический файл и его метаданные.

Схема основных полей совпадает с исторической постановкой. Дополнительный data_origin нужен для маркировки и не используется как признак. В git разрешены только этот CSV и его метаданные. Будущие реальные данные хранятся локально.

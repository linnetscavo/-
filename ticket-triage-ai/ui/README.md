# Интерфейс диспетчера
Доступен консольный интерфейс `../operator_cli.py`. Запуск описан в корневом README. Он принимает тему и текст, показывает две рекомендации, позволяет подтвердить или исправить каждую, сохраняет результат в SQLite.

Графическая форма из исходного MVP остаётся задачей backlog. Ей потребуются поля ввода, показ прогноза, редактирование, обработка ошибок и повтор сохранения без потери введённых данных.

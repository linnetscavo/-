# Интерфейс диспетчера

Здесь появятся поля темы и текста, кнопка получения прогноза, две рекомендации с уверенностями, выбор итоговых значений и кнопка сохранения. Интерфейс пока не реализован.

Кнопка сохранения должна сохранять и прогноз, и выбор человека. Показывать понятные сообщения об ошибках ввода, прогнозирования и сохранения. Сценарий: `../docs/mvp.md`.

# API
HTTP API пока запланирован. Функции recommend и resolve в `../operator_cli.py` выполняют прогноз и сохранение решения для консольного интерфейса.

Будущий HTTP слой должен вызывать ту же логику, проверять типы входа и возвращать две метки с отдельными уверенностями. Для пустого ввода, отсутствующей модели и ошибки хранилища нужны понятные ответы. Замер времени API ожидает реализации.

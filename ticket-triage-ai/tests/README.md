# Проверки
В корне проекта выполнить `python -m unittest -v`. Все данные тестов синтетические.

Автоматически проверяются схема, старые названия приоритетов, размеры исторического разбиения на искусственных 12 000 строках, отсутствие слов validation/test в словаре TF-IDF, размеры матриц, количество пропущенных критических, подтверждение и коррекция оператором, повторное чтение решений и отклонение повторной записи.

Notebook выполняется через Run All Cells в Jupyter. Полнота MVP дополнительно требует проверки будущего API и графической формы, обработки сбоев модели и записи, задержки API до 2 секунд, установки в чистом окружении и метрик на реальном тесте из 2 000 заявок. Эти проверки пока ожидают выполнения.
